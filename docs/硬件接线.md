## 2. XIAO-S3 ↔ 2.13 寸墨水屏 接线

> XIAO-S3 丝印编号（D1\~D10）与芯片 GPIO 不一一对应，必须按 GPIO 号接线。
> 屏幕侧 SPI 默认引脚：MOSI=IO9, SCK=IO7，已避开 USB(IO13/14) / Flash 占用脚。

| 墨水屏引脚      | XIAO-S3 丝印 | 实际 GPIO | 说明         |
| ---------- | ---------- | ------- | ---------- |
| VCC        | —          | 3V3     | 电源（注意峰值电流） |
| GND        | —          | GND     | 地          |
| DIN (MOSI) | D10        | GPIO9   | SPI 数据     |
| CLK (SCK)  | D8         | GPIO7   | SPI 时钟     |
| CS         | D4         | GPIO5   | 片选         |
| DC         | D2         | GPIO3   | 数据/命令      |
| RST        | D3         | GPIO4   | 复位         |
| BUSY       | D1         | GPIO2   | 忙信号        |

### 电路图（简化）

```
   XIAO-S3                  2.13" E-Paper
   +-------+                +-----------+
   |    3V3|--+-------------VCC         |
   |    GND|--+-------------GND         |
   |    D10|--------GPIO9--DIN (MOSI)   |
   |    D8 |--------GPIO7--CLK (SCK)    |
   |    D4 |--------GPIO5--CS           |
   |    D2 |--------GPIO3--DC           |
   |    D3 |--------GPIO4--RST          |
   |    D1 |--------GPIO2--BUSY         |
   +-------+                +-----------+
```

## 3. 电源方案

**本项目唯一电源方案：3.7V 锂离子电池（02050 / 厚 4mm / 450mAh）**

### 电池参数

- 标称电压：3.7V（充满 4.2V，放空 2.75V）
- 容量：450mAh
- 厚度：4mm（02050 尺寸，适配挂件外壳）
- 内阻：通常 < 100mΩ（远低于钮扣电池），瞬态电流能力强

### 电源链路

```
[USB-C] → [XIAO-S3 板载充电管理] → [3.7V 锂电 02050] → [XIAO-S3 板载 LDO] → 3V3
                                                            ↓
                                                  [墨水屏驱动板 24P] → [2.13" E-Paper]
```

- 3.7V 锂电**直连 XIAO-S3 的 BAT 引脚**，由板载 LDO 降压到 3.3V
- XIAO-S3 的 3V3 引脚再供电给墨水屏驱动板 24P
- 充电：插 USB-C 即可，板载充电管理自动处理

### 电压转换

电池电压（2.75\~4.2V）由 XIAO-S3 **板载 LDO** 降压到 3.3V，无需外置稳压芯片：

- 板载 LDO 静态电流 < 50μA
- 板载 LDO 峰值输出能力 ~600mA，足以应对墨水屏刷新 + WiFi 双峰值
- **禁止**将电池直接接到 3V3 引脚（会绕过 LDO，过压损坏屏幕）

### 续航估算

- XIAO-S3 deep sleep 电流：\~5mA（含 RTC）
- 每日唤醒一次，唤醒后平均 \~80mA × 30s ≈ 2400mA·s ≈ 0.67mAh
- 电池自放电：\~3%/月
- 理论续航：450 / 0.67 ≈ **670 天**（实际受温度与自放电影响，约 1.5\~2 年）

### 充电

XIAO-S3 **板载充电管理**（JAC7 方案），无需外置 TP4056：

- USB-C 插入后自动对电池充电
- 充电电流由板载电阻设定（约 200\~500mA，具体看 XIAO-S3 版本）
- 充满自动停止，绿灯指示

## 4. 注意事项

- 3.7V 锂电**直连 XIAO-S3 的 BAT 引脚**，由板载 LDO 降压到 3.3V；**禁止接到 3V3 引脚**；
- 3V3 引脚输出接墨水屏驱动板 24P 的 VCC，驱动板再连接墨水屏 FPC；
- 墨水屏驱动板 24P 上有 3.3V / 5V 跳线，**必须跳到 3.3V**（XIAO-S3 3V3 输出）；
- 墨水屏刷新瞬间功耗较大，**不要在刷新时拔掉电源**，会导致墨水屏永久残影；
- 建议把挂件外壳做成 3D 打印（PLA/PETG），留出 5mm × 5mm 透气孔；
- 电池座建议选带焊脚的弹簧型，结构更稳；
- XIAO-S3 的 D0/D6 接板载 LED（低电平点亮），避免占用做外设引脚。

## 5. 调试步骤

1. 先用 USB 给 XIAO-S3 烧录固件，串口监视器看日志：
   ```bash
   pio run -e seeed_xiao_esp32s3 -t upload
   pio device monitor
   ```
2. 看到 `[WIFI] 已连接` 后，访问 `http://<NAS>/api/health` 验证服务；
3. 观察墨水屏是否正确显示车票 / 无票画面；
4. 一切正常后断电，改为电池供电，重新上电观察首屏；
5. 等待到预设唤醒时间（默认 07:30），观察是否自动唤醒刷屏。

## 6. 常见问题

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 墨水屏全白不显示 | SPI 接线错误 / 驱动板 3.3V/5V 跳错 | 检查 MOSI/SCK/CS/DC + 跳线帽位置 |
| 墨水屏一直 BUSY 高 | RST/BUSY 接错 | 用万用表通断 RST/BUSY |
| 烧录失败 | USB 驱动 | 安装 CH343 / 板载 USB 驱动 |
| 唤醒后立刻掉电 | 电池虚焊 / 老化 | 重新焊接电池引脚或更换电池 |
| 字体显示为方块 | 字体未正确包含 | 改用 `u8g2_font_wqy16_t_gb2312a` |
