# 硬件接线说明

## 1. 物料清单

| 物料 | 数量 | 备注 |
|------|------|------|
| ESP32-D0WDQ6（V3 版本）-DevKitM-1 | 1 | 主控（4MB Flash） |
| 1.54 寸墨水屏（GDEW0154T8 / Waveshare 1.54 V2） | 1 | 200×200，单色 |
| 钮扣电池座 + CR2477 电池（或 2 颗 CR2032 并联） | 1 套 | 电源 |
| 100uF 电解电容 | 1 | 墨水屏刷新时缓冲 |
| 自锁按键（可选） | 1 | 立即唤醒 |
| 导线若干 | — | 连接 |

## 2. ESP32-D0WDQ6（V3 版本） ↔ 1.54 寸墨水屏 接线

> ESP32-D0WDQ6（V3 版本） 的 SPI 默认引脚：MOSI=IO6, SCK=IO7。请按以下连接。

| 墨水屏引脚 | ESP32-D0WDQ6（V3 版本） 引脚 | 说明 |
|------------|--------------|------|
| VCC        | 3V3          | 电源（注意峰值电流） |
| GND        | GND          | 地 |
| DIN (MOSI) | IO6 (GPIO6)  | SPI 数据 |
| CLK (SCK)  | IO7 (GPIO7)  | SPI 时钟 |
| CS         | IO5 (GPIO5)  | 片选 |
| DC         | IO4 (GPIO4)  | 数据/命令 |
| RST        | IO8 (GPIO8)  | 复位 |
| BUSY       | IO9 (GPIO9)  | 忙信号 |

⚠️ ESP32-D0WDQ6（V3 版本） **没有 IO10/11/12/13** 等常用 IO（被 flash 占用），请勿使用。

### 电路图（简化）

```
                +---------+
   ESP32-D0WDQ6（V3 版本）     |         |   1.54" E-Paper
   +-------+    |  3V3    |   +-----------+
   |    3V3|----+--VCC    |   |           |
   |    GND|----------GND|   |           |
   |    IO6|----------DIN|   |           |
   |    IO7|----------SCK|   |           |
   |    IO5|----------CS |   |           |
   |    IO4|----------DC |   |           |
   |    IO8|----------RST|   |           |
   |    IO9|----------BSY|   |           |
   +-------+    |  GND    |   +-----------+
                +---------+
```

## 3. 电源方案

### 方案 A：CR2477 直接供电（推荐，最简洁）

CR2477 单颗 1000mAh @ 3V，可工作数日到数周。

- 墨水屏刷新峰值电流约 25mA（持续 200ms），CR2477 完全可以提供；
- ESP32-D0WDQ6（V3 版本） 唤醒后连 WiFi 峰值约 250mA，**直接用 CR2477 会被拉垮**；
- 解决：增加 **1000uF 钽电容** 与电池并联，提供瞬态电流；
- 实测效果：CR2477 + 1000uF 电容可稳定运行。

### 方案 B：CR2032 × 2 并联 + 1000uF 电容

- 单颗 CR2032 仅 220mAh，2 颗并联 440mAh；
- 必须配合 **1000uF 钽电容或电解电容** 缓冲；
- 续航比 CR2477 差，但体积更小。

### 方案 C：USB 5V + LDO（仅开发调试用）

- 板载 USB 5V 经 AMS1117-3.3 LDO 降压；
- 长期接电可用此方案，省心。

## 4. 注意事项

- 墨水屏刷新瞬间功耗较大，**必须** 在 VCC 与 GND 之间并联电容；
- 不要在刷新时拔掉电源，会导致墨水屏永久残影；
- 建议把挂件外壳做成 3D 打印（PLA/PETG），留出 5mm × 5mm 透气孔；
- 电池座建议选带焊脚的弹簧型，结构更稳。

## 5. 调试步骤

1. 先用 USB 给 ESP32-D0WDQ6（V3 版本） 烧录固件，串口监视器看日志：
   ```bash
   pio run -t upload
   pio device monitor
   ```
2. 看到 `[WIFI] 已连接` 后，访问 `http://<NAS>/api/health` 验证服务；
3. 观察墨水屏是否正确显示车票 / 无票画面；
4. 一切正常后断电，改为电池供电，重新上电观察首屏；
5. 等待到预设唤醒时间（默认 07:30），观察是否自动唤醒刷屏。

## 6. 常见问题

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 墨水屏全白不显示 | SPI 接线错误 | 检查 MOSI/SCK/CS/DC |
| 墨水屏一直 BUSY 高 | RST/BUSY 接错 | 用万用表通断 RST/BUSY |
| 烧录失败 | USB 驱动 | 安装 CP210x / CH343 驱动 |
| 唤醒后立刻掉电 | 电池峰值电流不够 | 加大电容至 1000uF |
| 字体显示为方块 | 字体未正确包含 | 改用 `u8g2_font_wqy16_t_gb2312a` |
