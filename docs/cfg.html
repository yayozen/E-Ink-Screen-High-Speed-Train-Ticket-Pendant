2. 挂件图 - 不配置抓票相关信息或无票时显示

支持任意 JPG/PNG。浏览器自动 cover 缩放到 250×122、Atkinson 抖动成 1bit。 上传/清除后点 保存配置并重启 时通过 BLE 一同写入 NVS；下次"无票"时设备自动显示该图。

3. WiFi - 扫描并连接到附近第一个可用的 WiFi

4. 票务服务端（主 + 灾备）

主服务端故障 / 超时时自动尝试灾备；都缺配置时设备会显示 "CONFIG REQUIRED" 并自动进入配网

5. 共享密钥（AES-128）

用于加密 IMAP 配置 / 位图，设备和服务端必须一致。
配对完成时设备会调用 POST /key 自动同步到服务端，抓票时不再带密钥。

6. IMAP 邮箱（126/163 等）

强制 SSL/TLS，密码通过 AES-128 加密后写入 NVS

7. 定时唤醒

8. 刷新车票（强刷，不走缓存）

点击后退出配网模式，设备走正常抓票流程（WiFi→服务端→刷屏），前后端均跳过缓存。当前未保存的修改将丢失，蓝牙将断开。
